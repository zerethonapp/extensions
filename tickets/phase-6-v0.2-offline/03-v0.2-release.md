# P6-03 — v0.2 release (resubmit Chrome + Edge)

- **Status**: 🟡 plan
- **Phase**: 6
- **Priority**: P2
- **Estimate**: 1 day prep + review wait
- **Blocks**: —
- **Blocked by**: P6-02 (the ported tools must work end-to-end)

## Goal
Ship v0.2.0 with offline-capable tools to Chrome Web Store and Edge Add-ons. Update store listing to reflect the new capability.

## Why
End of the offline-bundling phase. Public release also updates store search ranking signals (recent activity = small boost).

## Acceptance criteria
- [ ] `src/manifest.json` version bumped to `0.2.0`
- [ ] `extensions/CHANGELOG.md` created (or updated if exists) — `0.2.0` entry lists the ported tools
- [ ] `docs/LISTING.md` updated:
  - "WHAT RUNS OFFLINE" section gains the actual ported tools (no longer placeholder)
  - Tagline updated to reference the offline capability
- [ ] Screenshots refreshed where offline behavior is now provable (e.g., screenshot 02 of side panel can now show an offline tool running with airplane-mode indicator)
- [ ] `npm run verify && npm run build:prod` clean
- [ ] Smoke test all surfaces on a fresh Chrome profile, including ALL ported tools with airplane mode on
- [ ] Upload to Chrome Web Store dashboard as a new version of the existing item (do NOT create a new item)
- [ ] Update permissions justifications if anything new is needed (likely nothing — we still only need the same 3 perms + 1 host)
- [ ] Re-confirm Privacy practices ticks — likely unchanged (offline = LESS data collection, not more)
- [ ] Submit for review; expect 3-7 days
- [ ] After approval: same process for Edge (upload same zip to the existing Edge item)
- [ ] Tag GitHub release `v0.2.0` with the zip attached

## Implementation notes
- Chrome version bumps are checked: cannot reuse `0.1.0`, must be `0.1.1` or higher
- Reviewers often look only at the diff vs previous version — if the diff is "new offline tools, no new permissions", review is usually faster than the original
- Don't change branding, name, or category in v0.2 — it triggers extra scrutiny. Save those for v0.3+ if ever needed.
- Update the `tools.zerethon.com/extension` landing page (P2-03) to surface the offline capability
