## Full description (paste verbatim — plain text, line breaks preserved)

```
Zerethon Tools puts the entire tools.zerethon.com catalog — 111+ free dev,
creator, and web3 utilities — one click away from your browser toolbar.

WHAT YOU CAN DO
• Search 111 tools instantly. JSON formatters, Base64, hash, regex, color,
  Markdown, CSV/SQL/YAML/XML converters, image converters, ETH unit, and more.
• Pin favorites to the top with a star.
• Recently-used tools appear at the top automatically.
• Right-click any selected text on any webpage to send it straight to the
  matching tool (Format as JSON, Decode/Encode Base64, SHA-256 hash,
  convert case, parse URL).
• Type "zt" in the address bar to autocomplete any of 111 tools and jump
  there with one Enter.
• Pin the launcher to Chrome's side panel and keep it open while you browse.
• Ctrl+Shift+Z (Cmd+Shift+Z on Mac) opens the launcher.

PRIVACY (READ THIS — IT IS THE WHOLE POINT)
• Zero analytics, zero telemetry, zero third-party SDKs.
• The extension has only the minimum permissions it needs (storage,
  contextMenus, sidePanel, and a single host: tools.zerethon.com).
• Your favorites and recents are stored on your device only.
• When you right-click selected text, the text is URL-safe-base64-encoded
  into the destination URL and decoded entirely in your browser by the tool
  page. It is never logged on our server.
• Full source on GitHub — every byte of the submitted package is reproducible
  with "npm run build".

111+ TOOLS — A FEW EXAMPLES
JSON Formatter · SQL Formatter · UUID Generator · Base64 Encoder · Hash
Generator · Color Converter · Markdown to HTML · CSV to JSON · YAML to JSON
· Unix Timestamp Converter · URL Parser · UTM Builder · Regex Data Generator
· Password Generator · Lorem Ipsum · Text Case Converter · Image Compressor
· QR-style generators · ETH Unit Converter · Wallet Address Validator · …

NOT A FORK, NOT A WRAPPER
This extension complements tools.zerethon.com — it opens each tool on the
website in a new tab, with the surface you wanted (popup, side panel,
context menu, omnibox) in your browser. Future versions may bundle the
most-used tools to run offline inside the extension itself.

NO ADS. NO PAYWALL. NO SUBSCRIPTION. NO SIGNUP.

Source: https://github.com/zerethonapp/extensions
Privacy policy: https://tools.zerethon.com/extension/privacy
Questions, requests, bug reports: support@zerethon.com
```
